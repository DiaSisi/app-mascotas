# 🐾 App de Gestión Veterinaria y Control de Seguros

Un sistema backend tipo "Notion para perritos" donde los usuarios pueden gestionar el historial médico (vacunas, desparasitantes) y los datos de suscripción a seguros de sus mascotas.

## 🚀 Requisitos previos
- Python 3.10 o superior
- Pip y Virtualenv
- PostgreSQL (opcional para producción, usa SQLite en desarrollo)
